🔒 Nessus Vulnerability Scan – Windows Host
📌 Overview

This project is part of Cyber Security Internship – Task 3. I performed a basic vulnerability scan on my Windows system using Nessus Essentials. The goal was to identify vulnerabilities, understand their risk, and suggest fixes.

📊 Scan Results

Total Findings: 144

Medium Risk: 9

Informational/Low: 135

High/Critical: None

Key Issues

HTTP TRACE / TRACK Methods Allowed → Disable in web server config.

SSL Certificate Expired → Replace with a valid certificate.

SSL Certificate Wrong Hostname → Reissue with correct hostname.
